How It Works

Step 1: Create a Stripe Payment Link

Go to your Stripe Dashboard → Products → Create Product. Set a one-time price (e.g. $9). Copy the payment link.

Step 2: Customize the Template

Copy the HTML template below. Replace the placeholder text with your product details. Paste your Stripe Payment Link URL.

Step 3: Deploy to GitHub Pages

git init
git add index.html
git commit -m "Initial commit"
gh repo create my-saas --public --push
gh api repos/YOUR_USER/my-saas/pages -X POST -F "source[branch]=master" -F "source[path]=/"

Your SaaS is live at youruser.github.io/my-saas in 2 minutes.
